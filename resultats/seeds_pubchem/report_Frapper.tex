\section*{How to read this report}
\addcontentsline{toc}{section}{How to read this report}
Structures are grouped by charge family, then by cluster size N$_x$. Within each series, isomers are ordered by increasing energy; the most stable one (the \emph{ground state}, GS) is highlighted and defines the zero of the \textbf{relative energy} $\Delta E_\text{rel}$ (kcal/mol). The \textbf{reaction energy} $E_\text{react}$ (kcal/mol) is computed against the pipeline's per-family reference reaction:
\begin{itemize}
\item neutral: $\mathrm{N}_x \rightarrow \tfrac{x}{2}\,\mathrm{N}_2$;
\item cation: $\mathrm{N}_x^{+} \rightarrow \tfrac{x-5}{2}\,\mathrm{N}_2 + \mathrm{N}_5^{+}$;
\item anion: $\mathrm{N}_x^{-} \rightarrow \tfrac{x-5}{2}\,\mathrm{N}_2 + \mathrm{N}_5^{-}$.
\end{itemize}
Each \texttt{.xyz} filename refers to a clean, VESTA-readable file in the \texttt{xyz\_clean/} folder alongside this report. All energies are at the GFN2-xTB level; structures are frequency-verified true minima and passed the fragmentation filter.
